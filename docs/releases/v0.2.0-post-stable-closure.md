## Operational Runbook Note

When approving a protected-environment deployment through the GitHub REST API,
the pending-deployments approval endpoint
(`POST /repos/{owner}/{repo}/actions/runs/{run_id}/pending_deployments`)
requires `environment_ids` as a **JSON integer array** supplied through
`--input`. A form-encoded `environment_ids[]` parameter may silently perform no
approval. This is a runbook note for operators, not product behavior.
