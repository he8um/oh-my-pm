## Publication gates that were satisfied

- **Dry run first.** Run
  [30748542496](https://github.com/he8um/oh-my-pm/actions/runs/30748542496) ran
  with `publish=false`: prepare and the cross-platform installed qualification
  succeeded, the publish job was skipped, and **no tag and no release were
  created** — verified twice afterwards.
- **Explicit confirmation.** The publish run required `publish=true` with the
  confirmation string exactly `RELEASE v0.5.4`.
- **Protected environment.** The publish job waited on the `github-release`
  environment and was approved before it ran.
- **Base lineage unchanged.** The workflow verified `v0.5.3` still exists on
  origin, still resolves to `fa50d0e50b1e527fb2ee5eeba9917b09d57c4614`, and is
  still a non-draft, non-prerelease, before publishing on top of it.
- **No overwrite.** The workflow refused to proceed if the tag or release already
  existed. `v0.5.3` was re-checked after publication and is unchanged.

## Installed command-surface smoke

The downloaded archive was extracted and installed into a temporary prefix:

- **Eight shims present and executable** — `ohmypm`, `ohmypm-mcp`, `oh-my-pm`,
  `oh-my-pm-mcp`, each with a POSIX and a `.cmd` launcher.
- **Canonical command** printed `OH MY PM status: healthy` and `version: 0.5.4`,
  with **empty stderr**.
- **Compatibility alias** produced **byte-identical stdout**, emitted the
  deprecation warning on **stderr only**, and kept it out of stdout.
- **Piped JSON** through the alias remained a parseable document.

tree contains the eleven deployed packages —

```text

planner  project-memory  providers  runtime  skills
```

— matching the `inBundle` claims in `packages.json` exactly, with
`@oh-my-pm/distribution` (the entrypoint layer) and `@oh-my-pm/examples`
(development-only) correctly absent. No Rust toolchain, no pnpm, and no
repository checkout is required; Node.js 20+ is the only runtime requirement.

## Behaviour statement

No user-visible behaviour changed in v0.5.4. Verified objectively rather than
asserted: `git diff v0.5.3..v0.5.4 -- cli/src mcp-server/src` shows only the two
version-string constants, with **no** change to MCP tool registration and **no**
change to any exit code. No command, flag, output format, failure code, MCP
schema, tool order, annotation, Project Brain schema, Project Memory store
format, or installed layout differs from v0.5.3. **No migration is required.**
