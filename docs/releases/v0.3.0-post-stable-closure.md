  command. **Status: deferred.**

## CI Maintenance Note

`actions/download-artifact` was upgraded from `@v5` (Node.js 20) to `@v7`
(Node.js 24) in the three active v0.3 workflows (`release-v0.3.yml`,
`release-v0.3-rc.yml`, `v0.3-installed-qualification.yml`) to clear the GitHub
Actions Node.js 24 forced-runtime warning. This is a version-only workflow-tooling
change: **no product behavior changed**, no version bump, no trigger/permission/
release-gate/asset-name/qualification-logic change, and the installed product
runtime remains Node.js 20+. The historical v0.1/v0.2 workflows were not touched.
