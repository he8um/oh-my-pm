# OH MY PM v0.3.0-rc.1 — Post-Publication Validation

## 1. Purpose

This report records the independent post-publication validation of the published
`v0.3.0-rc.1` prerelease and the stable GO / NO-GO decision for promoting it to a
stable `v0.3.0`. It validates the **actual published public artifacts** (not a
local rebuild) against the approved Project Brain product scope, then decides
whether stable preparation may begin. Publication of `v0.3.0` remains a separate,
explicitly authorized action; this report does not publish anything.

## 12. Migration

A deterministic format-1 store with three snapshots (lexical inventory order ≠
capture order) was planted with the installed Project Memory builders. Verified:
reads report `migrationRequired` and write nothing; `--migrate-store` preview
reports `wouldMigrateStore` and writes nothing; capture apply without the flag
fails controlled (exit 4); `capture --apply --migrate-store` performs one
migration and one capture; a backup is retained; the resulting manifest is store
format 2 with `recoveredV1` chronology; recovered order and latest pinning are
deterministic. Migration stays explicit, transactional, preview-first, and
backed up; there is no automatic read migration.
