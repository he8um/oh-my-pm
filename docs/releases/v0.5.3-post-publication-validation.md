## Publication gates that were satisfied

- **Dry run first.** Run
  [30746123581](https://github.com/he8um/oh-my-pm/actions/runs/30746123581) ran
  with `publish=false`: prepare, deterministic assets, and the cross-platform
  installed qualification all succeeded, the publish job was skipped, and **no
  tag and no release were created** — verified afterwards by
  `git ls-remote --tags origin refs/tags/v0.5.3` returning nothing and
  `gh release view v0.5.3` failing.
- **Explicit confirmation.** The publish run required `publish=true` with the
  confirmation string exactly `RELEASE v0.5.3`.
- **Protected environment.** The publish job waited on the `github-release`
  environment and was approved by the maintainer before it ran.
- **Base lineage unchanged.** The workflow verified `v0.5.2` still exists on
  origin, still resolves to `6c915e0ebea8fa6cb4c6f791c1b0dc621e745361`, and is
  still a non-draft, non-prerelease, before publishing on top of it.
- **No overwrite.** The workflow refused to proceed if the tag or release already
  existed. No existing tag, release, or asset was moved, replaced, or deleted.

## Installed command-surface smoke

The downloaded archive was extracted and installed into a temporary prefix with
`bin/ohmypm-install.mjs --prefix <tmp> --apply`:

- **Eight shims present and executable** — `ohmypm`, `ohmypm-mcp`, `oh-my-pm`,
  `oh-my-pm-mcp`, each with a POSIX and a `.cmd` launcher.
- **Canonical command:** `ohmypm status` printed `OH MY PM status: healthy` and
  `version: 0.5.3`, with **empty stderr**.
- **Compatibility alias:** the deprecated `oh-my-pm` shim, invoked with the same
  `status` argument, produced **byte-identical stdout**, emitted the deprecation
  warning on **stderr only**, and kept the warning out of stdout.
- **Piped JSON:** the same alias with `--json` remained a parseable JSON document
  on stdout, so a caller piping it is unaffected by the warning.
- **Installed manifest** separates the two families:
  `commands: ["ohmypm", "ohmypm-mcp"]`,
  `legacyCommands: ["oh-my-pm", "oh-my-pm-mcp"]`.

## Source independence

The installed prefix references no repository checkout: a search for the build
machine's source path under the installed tree returned nothing. The bundled
dependency tree contains the eleven deployed packages —

```text
application  cli  contracts  installer  kernel  mcp-server
planner  project-memory  providers  runtime  skills
```

— and `@oh-my-pm/examples` is correctly absent, since its code is
development-only and does not ship. Running the installed CLI required **no
Rust toolchain, no pnpm, and no repository checkout**; Node.js 20+ is the only
runtime requirement.
